One satirical sentence roasting lawmakers who would regulate AI, crypto and the internet yet cannot convert a file to PDF. The sentence (146 characters, inside the 320-character cap) lives in `entry.txt` and as a constant in `main.ts`, which cross-checks the two copies before writing; running the program writes the sentence, unchanged and with no trailing newline, to `/output/entry.txt` for the make.fun judge.

## Run it

```sh
node main.ts
```
